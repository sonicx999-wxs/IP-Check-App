使用文档

API Key 获取指南

本工具需要以下 API 服务的密钥才能正常工作：

1. IPQualityScore

注册地址：https://www.ipqualityscore.com/

免费额度：5,000次/月

2. IPinfo

注册地址：https://ipinfo.io/

免费额度：50,000次/月

3. Scamalytics

注册地址：https://scamalytics.com/

免费额度：100次/天

4. ProxyCheck.io

注册地址：https://proxycheck.io/

免费额度：1,000次/天

使用步骤

  1. 获取上述 API 服务的密钥
  2. 在检测工具页面点击右上角的设置图标
  3. 填入各 API 的密钥并保存
  4. 返回检测工具页面，输入 IP 地址开始检测
