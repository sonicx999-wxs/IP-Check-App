## 2. 详细变更内容

### 2.1 风险累积评分制实现

**变更文件**：`script.js`

**变更内容**：
- 实现了 `RiskAssessment` 类，用于规范化风险评估数据结构
- 修改了 `determineFinalVerdict` 函数，实现风险累积评分制
- 初始风险为0，发现疑点加分（罚），发现可信特征减分（赏）
- 最终分数越高，风险越大，范围0-100分

**变更前后对比**：
| 变更前 | 变更后 |
|--------|--------|
| 基于单个API评分或简单加权 | 风险累积评分制，综合多维度数据 |
| 固定的风险等级划分 | 动态计算的风险评分和Tier等级 |
| 缺乏风险计算透明度 | 提供详细的风险计算详情 |

**影响范围**：所有IP检测结果的风险评分和Tier等级计算

### 2.2 风险计算详情面板

**变更文件**：`render_core.js`

**变更内容**：
- 新增 `getRiskCalculationDetailsHTML` 函数，用于显示风险计算详情
- 显示风险累积项和风险稀释项
- 显示每个风险因素的具体分值

**变更前后对比**：
| 变更前 | 变更后 |
|--------|--------|
| 仅显示最终风险评分 | 显示风险评分的计算过程 |
| 缺乏风险因素透明度 | 显示每个风险因素的具体影响 |
| 用户无法了解评分依据 | 用户可以清楚了解评分的来源 |

**影响范围**：IP检测结果卡片的风险计算详情显示

### 2.3 Scamalytics评分风险累积项

**变更文件**：`script.js`

**变更内容**：
- 在风险计算中添加Scamalytics评分的风险累积项
- Scamalytics评分10-30分：乘以0.3的权重
- Scamalytics评分30-50分：乘以0.5的权重

**变更前后对比**：
| 变更前 | 变更后 |
|--------|--------|
| 风险计算未考虑Scamalytics评分 | Scamalytics评分直接影响风险评分 |
| 高Scamalytics评分可能被判定为低风险 | 高Scamalytics评分会增加风险评分 |
| 评分逻辑不完整 | 评分逻辑更加全面和准确 |

**影响范围**：所有IP检测结果的风险评分计算

### 2.4 风险评分显示修复

**变更文件**：`render_core.js`

**变更内容**：
- 修复了风险评分与适用场景显示为未知的问题
- 修改了 `hasValidScore` 的判断条件，从 `data.finalScore !== undefined` 改为 `typeof data.finalScore === 'number'`
- 优先使用 `assessment.tier` 信息显示风险等级

**变更前后对比**：
| 变更前 | 变更后 |
|--------|--------|
| 风险评分与适用场景可能显示为未知 | 正确显示风险评分与适用场景 |
| 卡片顶部风险评分可能与判定结果不一致 | 卡片顶部风险评分与判定结果一致 |
| 风险等级显示不准确 | 风险等级显示准确 |

**影响范围**：IP检测结果卡片的风险评分和适用场景显示
