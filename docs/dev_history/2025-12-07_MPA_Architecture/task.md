## 任务目标

将单页应用重构为多页应用 (MPA)，实现版本号统一管理，提高代码可维护性和扩展性。

## 核心需求

1. **多页应用架构**
   - 将原 `index.html` 重命名为 `app.html`（检测工具页）
   - 新建 `index.html` 作为门户主页
   - 新建 `guide.html` 作为使用文档页
   - 新建 `history.html` 作为历史记录页占位符

2. **统一导航栏**
   - 所有页面添加一致的导航栏
   - 固定在顶部，玻璃拟态风格
   - 当前页高亮显示
   - 包含主页、检测工具、历史记录、使用文档链接

3. **版本号统一管理**
   - 创建集中配置文件 `config.js`
   - 所有页面和脚本从配置文件读取版本号
   - 简化版本更新流程

4. **JS 安全性优化**
   - 增强脚本安全性，避免在非工具页报错
   - 优化事件监听器绑定

## 技术约束

- 保持现有 DOM ID 引用
- 使用原生 JavaScript，不引入新框架
- 保持响应式设计
- 遵循项目现有的代码风格和规范
